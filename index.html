Dental benefit summary extractor

Unofficial. Does not invent values. The parser is extract.py from this site, loaded unchanged and run in your browser with Pyodide. Nothing is sent to a server.

Pages are rendered to images first, then Tesseract reads those images. That is OCR, not a vision LLM, and it is not the PDF text layer. Pasted text and a .txt upload are not OCR'd. They go straight to extract_text.

If a file is selected, it is used instead of the paste box. Clear the file choice to use pasted text.
